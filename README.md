# 量化回测框架

这是一个基于 Backtrader 和 Tushare/Akshare 的轻量级量化交易回测框架.

## 功能

- 支持 Tushare 和 Akshare 双数据源.
- 灵活的策略与参数配置.
- 清晰的项目结构, 易于扩展.
- 对用户友好的、可读性强的输出结果 (日志, 报告, 图表).

## 项目结构

```
.
├── config.py               # 配置文件 (API密钥, 数据源, 回测参数)
├── data_fetcher.py         # 数据获取模块
├── main.py                 # 回测主程序
├── README.md               # 项目说明文档
├── requirements.txt                # Python 依赖库
├── doc                             # 文档目录
│   ├── 仓位管理.md                  # 仓位管理策略文档
│   └── 仓位管理使用指南.md           # 使用指南
├── strategies                      # 策略目录
│   ├── macd_strategy.py            # MACD 示例策略
│   └── position_management_strategy.py  # 仓位管理策略
├── main.py                         # MACD策略回测主程序
└── main_position_management.py     # 仓位管理策略回测主程序
```

## 可用策略

### 1. MACD策略
基于MACD指标的趋势跟踪策略，适合趋势明显的市场。

**运行方式**：
```bash
python main.py
```

### 2. 仓位管理策略 ⭐ 新增
基于波动率的多周期动态仓位管理策略，通过分散投资和动态调仓实现风险控制。

**运行方式**：
```bash
python main_position_management.py
```

**特点**：
- 多周期分散投资（默认4个周期）
- 根据波动率阈值自动调仓
- 考虑GDP增长的资金基准
- 详细的操作日志和周期分析

**详细说明**：请参考 [`doc/仓位管理使用指南.md`](doc/仓位管理使用指南.md)
```

## 使用指南

### 1. 安装依赖

在项目根目录下运行以下命令来安装所有必需的库:

```bash
pip install -r requirements.txt
```

### 2. 配置参数

打开 `config.py` 文件, 你可以根据需求修改回测的各项参数.

- **TUSHARE_TOKEN**: 如果使用 Tushare, 请填入你的密钥.
- **DATA_SOURCE**: 选择数据源, `'tushare'` 或者 `'akshare'`.
- **STOCK_CODE**: 目标证券的代码.
- **START_DATE / END_DATE**: 回测周期.
- **INITIAL_CASH**: 初始资金.
- **ENABLE_BENCHMARK**: 是否在报告中加入上证指数作为表现基准 (需要 Tushare Pro 权限).

### 3. 运行回测

配置完成后, 运行主程序:

```bash
python main.py
```

## 输出结果说明

程序运行结束后, 会在项目根目录生成以下三个文件:

### 1. `backtest_results.txt` - 总结报告

这是本次回测的**总结性报告**, 包含了最终的资产情况, 收益率, 夏普比率, 最大回撤, 以及总体的交易统计 (总交易次数, 胜率等).

### 2. `backtest_plot.png` - 结果图表

这是回测过程的**可视化图表**.
- **主图** 为 K 线和您的买卖点箭头.
- **下方子图** 为策略中使用的技术指标 (例如 MACD).
- 图表经过优化, 布局清晰, 移除了不必要的干扰信息.

### 3. `operation_log.csv` - 详细交易日志

这是您最关心的**逐笔操作记录**, 您可以用 Excel 或任何文本编辑器打开. 每一行代表一次买入或卖出操作.

| 列标题         | 说明                                         |
| :------------- | :------------------------------------------- |
| **操作日期**   | 执行本次买入或卖出操作的日期.                |
| **操作类型**   | `买入` 或 `卖出`.                            |
| **成交价格**   | 本次操作的每股成交价格.                      |
| **成交数量**   | 本次操作的成交股数.                          |
| **成交后持仓** | 本次操作完成后, 您账户中持有的总股数.        |
| **成交后现金** | 本次操作完成后, 您账户中剩余的现金.          |
| **手续费**     | 本次操作所花费的手续费.                      |
