# 仓位管理策略 (Position Management Strategy)

## 策略概述

这是一个基于波动率的多周期动态仓位管理策略。核心思想是将总资金分配到多个独立周期，每个周期根据其波动率阈值(VIX)独立进行加仓或减仓操作，同时考虑GDP增长率作为资金基准增长。

## 策略原理

### 1. 初始资金分配

总资金 `Position` 按照预设比例分配到多个独立周期：
- `Cycle_A_position = Position × 比例_A`
- `Cycle_B_position = Position × 比例_B`
- ...以此类推

每个周期拥有独立的波动率阈值 `VIX_X`，用于判断何时触发调仓。

### 2. 调仓触发逻辑

**对每个周期独立运行以下逻辑：**

从上次调仓（或初始建仓）开始，经过 `day` 个交易日后，当前仓位市值相对于**上次调仓后的金额**变化达到 ±VIX_X% 时，触发调仓操作。

#### 触发条件判断：
```
当前市值 = 持仓数量 × 当前价格
上次调仓金额 = last_position_value
涨跌幅 = (当前市值 - 上次调仓金额) / 上次调仓金额

if 涨跌幅 <= -VIX_X%:  # 仓位下跌
    触发补仓
elif 涨跌幅 >= +VIX_X%:  # 仓位上涨
    触发减仓
```

### 3. 调仓规则

**GDP增长率假设**: 7% (年化)  
**每日增长率**: GDP / 250 = 0.028% (假设一年250个交易日)

#### 补仓规则 (仓位下跌VIX_X%)
```
目标金额 = 初始仓位 × (1 + 0.07/250 × day)
补仓金额 = 目标金额 - 当前市值
```

#### 减仓规则 (仓位上涨VIX_X%)
```
目标金额 = 初始仓位 × (1 + 0.07/250 × day + VIX_X/4)
减仓金额 = 当前市值 - 目标金额
```

**注意事项：**
- `day` 是从上次调仓算起的交易日数
- 同一交易日内第二次触发时，`day` 视为 0
- 假设资金无限，可以无限补仓或减仓

### 4. 资金管理

- **独立核算**: 每个周期的资金独立核算，互不影响
- **无限资金假设**: 不考虑持仓外的可用资金限制
- **统计追踪**: 
  - 记录每个周期累计投入的总资金
  - 记录每个周期的最大追加投资金额
  - 记录回测结束时每个周期的市值

## 默认参数配置

### 周期配置 (4个周期)

| 周期编号 | 初始仓位比例 | 初始金额 (基于100,000) | VIX阈值 |
|---------|------------|---------------------|---------|
| Cycle_1 | 10%        | 10,000              | 2%      |
| Cycle_2 | 20%        | 20,000              | 4%      |
| Cycle_3 | 30%        | 30,000              | 8%      |
| Cycle_4 | 40%        | 40,000              | 16%     |

### 全局参数

- **总初始资金**: 100,000
- **GDP增长率**: 7% (年化)
- **交易手续费**: 0.005% (可配置)
- **回测标的**: 可配置 (如 000300.SH 沪深300)
- **回测时间**: 可配置 (支持牛市/熊市/震荡市测试)

## 输出指标

### 1. 各周期指标

对每个周期输出：
- **初始投入**: 周期初始仓位金额
- **累计投入**: 整个回测期间累计投入的总资金
- **最大追加**: 单次最大追加投资金额
- **期末市值**: 回测结束时的持仓市值
- **绝对收益**: 期末市值 - 累计投入
- **收益率**: (期末市值 - 初始投入) / 初始投入 × 100%
- **调仓次数**: 总共触发调仓的次数
- **补仓次数**: 触发补仓的次数
- **减仓次数**: 触发减仓的次数
- **最大回撤**: 相对于历史最高市值的最大回撤百分比

### 2. 整体策略指标

- **总初始投入**: 所有周期初始投入之和
- **总累计投入**: 所有周期累计投入之和
- **总最大追加**: 所有周期最大追加投资之和
- **总期末市值**: 所有周期期末市值之和
- **总绝对收益**: 总期末市值 - 总累计投入
- **总收益率**: (总期末市值 - 总初始投入) / 总初始投入 × 100%
- **总调仓次数**: 所有周期调仓次数之和
- **夏普比率**: 策略收益的风险调整后收益
- **最大回撤**: 整体策略的最大回撤

### 3. 对比指标

- **买入持有收益率**: 同期买入持有标的的收益率
- **相对表现**: 策略收益率 - 买入持有收益率

## 策略特点

### 优势
1. **多周期分散**: 不同VIX阈值适应不同市场波动
2. **动态平衡**: 自动高抛低吸，逆向操作
3. **趋势适应**: 考虑GDP增长，顺应长期趋势
4. **风险控制**: 分散投资，降低单一周期风险

### 适用场景
- 震荡市场：频繁触发调仓，高抛低吸
- 趋势市场：测试策略在单边行情中的表现
- 长期投资：利用GDP增长基准，适合长期持有

## 实现说明

策略基于 Backtrader 框架实现，主要模块：
- **策略类**: `PositionManagementStrategy` 继承 `bt.Strategy`
- **周期管理**: 每个周期独立跟踪持仓、调仓记录
- **数据记录**: 详细记录每次调仓操作和资金变化
- **结果输出**: 生成报告、图表和操作日志
