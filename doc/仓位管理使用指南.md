# 仓位管理策略使用指南

## 📖 策略说明

仓位管理策略是一个基于波动率的多周期动态仓位管理策略。详细的策略原理请参考 [`doc/仓位管理.md`](../doc/仓位管理.md)。

## 🚀 快速开始

### 1. 运行回测

```bash
python main_position_management.py
```

### 2. 配置参数

在 `config.py` 中修改以下参数：

#### 回测基础配置
```python
STOCK_CODE = '000300.SH'      # 回测标的
START_DATE = '20230201'       # 开始日期
END_DATE = '20240201'         # 结束日期
ENABLE_BENCHMARK = True       # 是否启用基准对比
```

#### 策略参数配置
```python
class PositionManagementParams:
    total_initial_cash = 100000.0  # 总初始资金
    gdp_rate = 0.07                # GDP年化增长率
    
    # 周期配置
    cycles = [
        {
            'id': 'Cycle_1',
            'ratio': 0.10,              # 仓位比例 10%
            'initial_cash': 10000.0,    # 初始金额
            'vix_threshold': 0.02       # VIX阈值 2%
        },
        # ... 更多周期
    ]
```

## 📊 输出结果

运行后会在 `results/` 目录下生成以下文件：

### 1. `backtest_results.txt` - 总结报告

包含：
- 各周期详细数据（初始投入、累计投入、最大追加、期末市值、收益率等）
- 整体策略表现
- 对比指标（买入持有、基准收益）

示例输出：
```
【Cycle_1】
  VIX阈值:        2.0%
  初始投入:       10,000.00
  累计投入:       11,866.11
  最大追加:        3,474.24
  期末市值:        9,653.13
  收益率:            -3.47%
  调仓次数:               2 (补仓:2, 减仓:0)
  最大回撤:          16.33%
```

### 2. `operation_log.csv` - 操作日志

记录每次调仓操作的详细信息：
- 日期、周期ID、操作类型
- 成交价格、操作数量、操作金额
- 操作后持仓、操作后市值
- 距上次调仓天数、触发涨跌幅
- 目标金额、手续费

### 3. `cycle_details.csv` - 周期详情

记录每个交易日各周期的详细状态：
- 当前价格、持仓数量、当前市值
- 距上次调仓天数、相对涨跌幅
- 累计投入、最大回撤

## 📈 策略核心逻辑

### 触发条件
- **补仓触发**：仓位相对上次调仓下跌 ≥ VIX阈值
- **减仓触发**：仓位相对上次调仓上涨 ≥ VIX阈值

### 调仓公式

**补仓**（仓位下跌VIX%）：
```
目标金额 = 初始仓位 × (1 + GDP/250 × day)
```

**减仓**（仓位上涨VIX%）：
```
目标金额 = 初始仓位 × (1 + GDP/250 × day + VIX/4)
```

其中：
- `day` = 距上次调仓的交易日数
- `GDP` = 年化GDP增长率（默认7%）
- 同日第二次调仓时，`day` = 0

## 💡 策略特点

### 优势
1. **多周期分散**：不同VIX阈值适应不同市场波动
2. **动态平衡**：自动高抛低吸，逆向操作
3. **趋势适应**：考虑GDP增长，顺应长期趋势
4. **风险控制**：分散投资，降低单一周期风险

### 适用场景
- **震荡市场**：频繁触发调仓，高抛低吸效果明显
- **趋势市场**：测试策略在单边行情中的表现
- **长期投资**：利用GDP增长基准，适合长期持有

## 📝 示例回测结果分析

以熊市周期（2023-02-01 至 2024-02-01）为例：

```
总收益率:        -6.69%
买入持有收益率:  -23.31%
相对表现:        +16.63%  ✅ 跑赢买入持有
```

**关键发现**：
- 在熊市中，策略通过逐步补仓降低了整体亏损
- 相对买入持有策略，减少了约16.63%的亏损
- 总调仓次数：10次（全部为补仓）
- 总追加投入：17,506.91（相对初始10万）

## 🛠️ 自定义周期配置

你可以根据需求自定义周期数量和参数：

```python
cycles = [
    {
        'id': 'Conservative',      # 保守型
        'ratio': 0.30,
        'initial_cash': 30000.0,
        'vix_threshold': 0.05      # 5% 触发
    },
    {
        'id': 'Aggressive',        # 激进型
        'ratio': 0.70,
        'initial_cash': 70000.0,
        'vix_threshold': 0.15      # 15% 触发
    },
]
```

## ⚠️ 注意事项

1. **资金假设**：策略假设资金无限，可以无限补仓
2. **交易单位**：当前设置为1股为单位（适应指数等高价标的）
3. **手续费**：默认为0.005%，可在 `config.py` 中修改
4. **数据源**：支持 Tushare、Akshare、Baostock，在 `config.py` 中配置
