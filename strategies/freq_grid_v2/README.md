# Freq Grid V2 策略说明文档

## 📋 策略概述

**Freq Grid V2** 是基于 `Freq(1).md` 文档实现的优化版**动态网格仓位管理策略**。

### 核心思想

根据收益率将投资过程划分为 **6 个区域（A→F）**，在不同区域采用不同的加仓/减仓规则：

- **区域 A (初始建仓)**：金字塔逆势加仓 + 小幅减仓
- **区域 B (严重亏损)**：只加仓不减仓
- **区域 C (亏损可控)**：阶梯减仓回血 + 小幅加仓
- **区域 D (慢速置换)**：加速阶梯减仓回收本金
- **区域 E (快速置换)**：大幅阶梯减仓快速回本
- **区域 F (利润复利)**：本金全回收，利润高抛低吸

---

## 🔧 相比原版的优化

### 1. **修复加仓公式错误**

- ❌ **原实现**: `Bg_new = Bg_current * y / 100`
- ✅ **优化后**: 使用正确的金字塔公式 `Bg = Bo × (Ao/price)^K`

### 2. **完善区域转换逻辑**

- 增加了区域 D 的收益率上限检查（避免 i=50%时仍在 D 区）
- 实现了仓位恢复机制（D→C 时恢复到 D2 股数）

### 3. **实现全局核算体系**

- 新增 `总投入本金`、`总回收现金`、`全局净利润` 等指标
- 新增 `全局累计收益率`、`全局年化收益率` 作为权威评估依据
- 绘制 `全局资产曲线` 和 `双收益率对比图`

### 4. **资金使用优先级管理**

- 加仓时优先使用 `累计减仓资金(S_acc)`
- 不足时才使用新资金并增加 `Ba`

### 5. **增强的可视化**

- 7 个子图综合展示：
  1. 价格 + 买卖点 + 区域背景色
  2. 资金构成 (Bc, Ba, S_acc)
  3. 全局资产曲线
  4. 双收益率对比
  5. 区域分布饼图
  6. 回撤曲线
  7. 现金流分析

## 🚀 快速开始

### 1. 配置参数

编辑 `config.py`：

```python
class StrategyConfig:
    # 资金配置
    total_initial_cash = 1_000_000  # 初始资金100万

    # 核心参数
    Ao = 35.30      # 初始基准价
    Af = 25.00      # 预期最低价
    Bo = 200_000    # 初始仓位20万

    threshold_mode = 'fixed'
```

## 📊 核心公式

### 金字塔系数 K

```
K = ln(Bf/Bo) / ln(Ao/Af)
```

### 目标仓位计算

```
Bg = Bo × (Ao / current_price)^K
```

限制在 `[Bo, Bf]` 范围内。

### 收益率计算

```
i = (Bc - Ba) / Ba
```

其中：

- `Bc` = 当前持仓市值
- `Ba` = 实际累计投入本金

### 全局年化收益率

```
全局年化 = (1 + 全局累计收益率)^(1/年数) - 1
```

## ⚙️ 参数调优建议

### 针对指数（如沪深 300）

```python
Ao = 35.30      # 当前点位 / 100
Af = 25.00      # 历史最低点 × 0.85 / 100
Bo = 200_000    # 20% 初始仓位
Bf = 800_000    # 80% 最大仓位
fixed_threshold = 0.035  # 3.5% (指数波动小)
buffer_days = 2          # 增加缓冲防止震荡
```

### 针对个股（如茅台）

```python
Ao = 1800       # 买入时价格
Af = 1200       # 估算最低价（基于历史回撤）
Bo = 150_000    # 15% 初始仓位
Bf = 700_000    # 70% 最大仓位
threshold_mode = 'dynamic'  # 使用动态阈值
buffer_days = 1             # 个股趋势性强
```

## ⚠️ 风险提示

1. **路径依赖**: 策略表现高度依赖价格路径
2. **震荡市磨损**: 无趋势市场会频繁交易
3. **Af 估算风险**: 如跌破 Af，需重新评估参数
4. **流动性风险**: 大额交易注意滑点
5. **不含极端事件**: 回测未考虑黑天鹅

## 📈 评估指标说明

### 策略内部口径

- `期末收益率` - 基于最终持仓计算
- `最大投入Ba` - 策略实际占用资金

### 全局核算口径（权威）

- `全局年化收益率` - 考虑全周期资金进出
- `全局最大回撤` - 基于总资产曲线
- `本金回收时点` - 何时 S_acc >= Ba

**重要**: 长周期评估以**全局核算口径**为准！
