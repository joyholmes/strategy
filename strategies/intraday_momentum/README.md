# 日内动量突破策略 (Intraday Momentum Breakout)

## 策略概述

本策略是一种日内短线交易策略，基于量价关系和分时均线进行买卖决策。核心思想是捕捉开盘后具有强势动量特征的股票，同时通过严格的止损条件控制风险。

---

## 策略参数

| 参数名称               | 参数值    | 说明                         |
| ---------------------- | --------- | ---------------------------- |
| 买入触发时间           | 09:35:01  | 早盘开盘后 5 分钟            |
| 卖出检查时间(集合竞价) | 09:24:59  | 集合竞价结束前               |
| 卖出触发时间(盘中)     | 09:35:01  | 与买入触发时间一致           |
| 量比阈值               | 2.5       | 量比需大于此值               |
| 最低价跌幅上限         | 1%        | 最低价跌幅不超过此值         |
| 现价与最低价涨幅上限   | 2%        | 现价相对最低价涨幅不超过此值 |
| 集合竞价跌幅阈值       | 2%        | 触发卖出的跌幅阈值           |
| 分时均线跌破持续时间   | 5 分钟    | 跌破均线后的观察时间         |
| 单只个股最大交易金额   | 50,000 元 | 仓位控制                     |
| 多股买入资金阈值       | 50,000 元 | 超过此金额可分散买入         |

## 买入条件

### 触发时间

- **09:35:01** 后开始检测

### 必要条件（需同时满足）

| 序号 | 条件     | 公式                            | 说明                  |
| ---- | -------- | ------------------------------- | --------------------- |
| 1    | 量比条件 | `量比 > 2.5`                    | 反映当前成交活跃程度  |
| 2    | 价格强势 | `现价 > 开盘价`                 | 价格位于开盘价之上    |
| 3    | 均线支撑 | `现价 > 分时均线价格`           | 价格位于分时均线之上  |
| 4    | 下跌可控 | `(最低价 - 昨收) / 昨收 ≥ -1%`  | 盘中最大跌幅不超过 1% |
| 5    | 涨幅可控 | `(现价 - 最低价) / 最低价 ≤ 2%` | 避免追高买入          |

### 多股选择规则

```
IF 符合条件股票数量 >= 2:
    IF 可用资金 > 50,000元:
        按涨幅由高到低排序，依次买入
    ELSE:
        选择涨幅最大的股票买入
```

### 仓位控制

- **单只个股最大交易金额**: 50,000 元
- 若资金充足，可同时持有多只股票

---

## 卖出条件

### 条件一：集合竞价卖出

| 触发时间 | 条件                    | 说明               |
| -------- | ----------------------- | ------------------ |
| 09:24:59 | `集合竞价股价跌幅 ≥ 2%` | 不论盈亏，立即卖出 |

**计算公式**:

```
集合竞价跌幅 = (集合竞价价格 - 昨日收盘价) / 昨日收盘价
```

### 条件二：盘中卖出（09:35:01 后）

满足**任一条件**即触发卖出：

| 序号 | 条件             | 公式                                |
| ---- | ---------------- | ----------------------------------- |
| 1    | 跌破开盘价       | `现价 < 当日开盘价`                 |
| 2    | 持续跌破分时均线 | `现价 < 分时均线价格` 且持续 5 分钟 |

**条件 2 详细逻辑**:

```
record_break_time = None

IF 现价 < 分时均线价格:
    IF record_break_time is None:
        record_break_time = current_time  # 记录首次跌破时间
    ELSE:
        IF current_time - record_break_time >= 5分钟:
            触发卖出
ELSE:
    record_break_time = None  # 价格回到均线上方，重置计时
```

## 风险提示

1. **滑点风险**: 实盘交易中，高量比股票可能存在较大滑点
2. **流动性风险**: 需关注股票的流动性，避免买入后无法及时卖出
3. **策略时效性**: 本策略针对日内短线，需确保网络和交易系统的稳定性
4. **市场环境**: 策略在单边下跌市中可能频繁触发止损
