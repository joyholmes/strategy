## 🎯 策略核心特性

### 1. 多周期独立管理
- 每个周期独立跟踪持仓和资金
- 不同VIX阈值适应不同波动特征
- 互不干扰，分散风险

### 2. 动态调仓机制
- **补仓触发**：下跌≥VIX% → 补仓至目标金额
- **减仓触发**：上涨≥VIX% → 减仓至目标金额
- 考虑GDP增长基准，顺应长期趋势

### 3. 详细统计追踪
- 实时跟踪每个周期的资金变化
- 记录最大追加投资金额
- 计算最大回撤
- 统计调仓次数和类型

### 4. 灵活配置
- 可自定义周期数量
- 可调整VIX阈值
- 可修改GDP增长率
- 支持不同标的和时间段

## 🔧 技术实现亮点

### 1. 周期跟踪器设计
```python
class CycleTracker:
    - 独立管理每个周期的状态
    - 计算涨跌幅和目标金额
    - 判断调仓触发条件
    - 更新统计数据
```

### 2. 同日多次调仓处理
- 使用 `rebalanced_today` 标记
- 第二次调仓时 `day=0`
- 避免重复计算天数

### 3. 交易单位适配
- 从100股改为1股为单位
- 适应指数等高价标的
- 提高资金利用率

### 4. 详细日志记录
- 操作日志：每次调仓的完整信息
- 周期详情：每日状态快照
- 便于后续分析和优化

## 📈 使用建议

### 1. 参数调优
- **VIX阈值**：根据标的波动特性调整
  - 高波动标的：可适当提高阈值（10%-20%）
  - 低波动标的：可降低阈值（2%-5%）
- **周期配置**：根据风险偏好调整比例
  - 保守型：增加低VIX周期比例
  - 激进型：增加高VIX周期比例

### 2. 回测建议
- 测试多个市场周期（牛市/熊市/震荡）
- 对比不同VIX阈值组合
- 分析 `cycle_details.csv` 了解细节
- 关注最大回撤和调仓频率

### 3. 实盘注意事项

- 注意交易成本（手续费、滑点）
- 关注流动性问题
- 定期评估和调整参数
