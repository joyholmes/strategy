# 估值定投/交易策略

## 1. 策略核心理念

基于"均值回归"原理，利用指数或个股的估值指标（PE-TTM 或 PB）在历史区间中的相对位置（分位点）来决定仓位。

- **低估时**（分位点低）：增加仓位，获取戴维斯双击收益。
- **高估时**（分位点高）：降低仓位，规避下跌风险，锁定收益。

## 2. 核心指标

- **PE-TTM (滚动市盈率)**：适用于盈利稳定的宽基指数（如沪深 300）。
- **PB (市净率)**：适用于周期性较强或盈利不稳定的品种（如证券、银行）。
- **历史分位点**：当前估值在过去 N 年（如 5 年或 10 年）中的排名百分比。

## 3. 交易逻辑（分段式仓位管理）

| 估值分位点 (Percentile) | 估值状态 | 目标仓位 (Target Position) | 操作                |
| :---------------------- | :------- | :------------------------- | :------------------ |
| **0% - 20%**            | 极度低估 | **100%** (满仓)            | 大幅买入            |
| **20% - 40%**           | 低估     | **70%**                    | 保持高仓位/适度买入 |
| **40% - 60%**           | 适中     | **50%**                    | 标配/持有不动       |
| **60% - 80%**           | 高估     | **20%**                    | 减持/保留底仓       |
| **80% - 100%**          | 极度高估 | **0%** (空仓)              | 清仓止盈            |

## 4. 关键参数 (Config)

- `VALUATION_TYPE`: 'PE' 或 'PB'
- `LOOKBACK_YEARS`: 历史分位点计算周期，默认 5 年。
- `POSITION_TIERS`: 仓位分档配置（如上表所示）。
- `REBALANCE_FREQ`: 调仓频率（如每月、每周或每日检查）。

## 5. 数据需求

需要每日的 **PE-TTM** 和 **PB** 数据。
_注意：数据源必须支持返回每日估值数据。_

## 5. 回测机制说明 (重要)

为了确保策略逻辑的严谨性，本策略采用了 **双区间回测机制**：

### 5.1 数据预载区间 (Data Warm-up Period)

- 回测开始前，程序会自动向前加载一段历史数据（默认为 `LOOKBACK_YEARS=5` 年）。
- **目的**: 解决冷启动问题。如果不预加载数据，回测第一天的历史样本只有一个，计算出的百分位点将毫无意义。通过预载，策略在正式交易的第一天就已经拥有了过去 5 年的估值分布全景。
- **示例**: 若设置回测区间为 2020-2025，程序会自动加载 2015-2020 的数据用于计算初始分位点。

### 5.2 策略运行区间 (Backtest Period)

- 实际进行模拟交易的时间段，资金曲线只统计此区间的表现。
- 分位点计算采用 **滚动窗口** 或 **累计历史** 模式，模拟真实交易环境下的信息获取（不使用未来数据）。

## 6. 输出结果说明

回测完成后，`results/` 目录下会生成详细的分析文件：

1.  `backtest_results.txt`: **深度回测报告**

    - **区间说明**: 明确展示预载区间和实际回测区间。
    - **策略标准核实**: 列出仓位映射表，并给出关键分位点（20%, 80%等）对应的 **具体 PE/PB 绝对值**，方便用户核对。
    - **核心指标**: 包含年化收益、夏普比率、最大回撤、超额收益等。

2.  `valuation_plot.png`: **策略可视化图表**

    - **子图 1**: 价格走势 + **买卖点标记** (红三角买入，绿三角卖出)。
    - **子图 2**: 资产曲线 vs **基准收益** (买入持有策略)。
    - **子图 3**: 估值分位点趋势 + **仓位比例** (双轴显示，直观展示低吸高抛过程)。

3.  `details.csv` & `operation_log.csv`:
    - 提供每日详细数据和每一笔交易的成交明细，便于逐单核对。

## 7. 优势与风险

- **优势**：

  - **买在底部**: 通过绝对低估值分位建仓，具有很高的安全边际。
  - **自动止盈**: 在泡沫形成初期自动减仓，保住胜利果实。
  - **适应性**: 相比固定 PE 数值策略，百分位策略能适应市场估值中枢的长期变化。

- **风险**：
  - **估值陷阱**: 低估值可能源于基本面恶化（如行业衰退），看似便宜但可能长期阴跌。
  - **踏空风险**: 在超级单边牛市中，策略可能过早清仓，无法吃到最后一段疯狂的涨幅。
  - **时间成本**: 价值回归往往漫长，需要极强的耐心（可能面临长达数年的浮亏或震荡）。
