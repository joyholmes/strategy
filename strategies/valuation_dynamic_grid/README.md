# 估值动态网格策略 (Valuation Dynamic Grid)

## 1. 策略核心思想

本策略是对传统“估值-仓位”线性映射模型的改进，引入了**非对称动态网格**机制。

### 1.1 核心公式

基础仓位依然遵循线性回归逻辑：
$$ \text{Target Position} = 100\% - \text{Percentile} $$

即：

- 估值分位 10% -> 仓位 90%
- 估值分位 50% -> 仓位 50%
- 估值分位 90% -> 仓位 10%

### 1.2 动态非对称网格 (核心创新)

为了实现“低买容易、高卖容易”的非均匀特性，我们引入动态阈值（Buffer）：

1.  **在低估区域 (如分位 < 20%)**：
    - **买入极敏感**：只要实际仓位略低于目标（偏差 > 1%），立即触发买入。这保证了在底部只要有机会就吸筹。
    - **卖出极迟钝**：实际仓位必须显著高于目标（偏差 > 8%），才触发卖出。这防止了在底部刚刚反弹就过早丢失筹码。
2.  **在高估区域 (如分位 > 80%)**：
    - **卖出极敏感**：只要实际仓位略高于目标（偏差 > 1%），立即触发卖出。
    - **买入极迟钝**：实际仓位必须显著低于目标（偏差 > 8%），才触发买回。

### 1.3 阈值函数

阈值随分位点线性变化：

- **买入阈值** ($T_{buy}$): 从 1% (低位) 线性增加到 8% (高位)。
- **卖出阈值** ($T_{sell}$): 从 8% (低位) 线性减小到 1% (高位)。

---

## 2. 参数配置 (`config.py`)

| 参数             | 默认值 | 说明                              |
| :--------------- | :----- | :-------------------------------- |
| `metric`         | 'pb'   | 估值指标 (PE/PB)，银行股建议用 PB |
| `lookback_years` | 10     | 滚动分位计算的回溯窗口            |
| `min_threshold`  | 0.01   | 最小网格间距 (最敏感状态)         |
| `max_threshold`  | 0.08   | 最大网格间距 (最迟钝状态)         |

---

## 3. 优势分析

1.  **避免“踏空”**：低位买入不仅仓位大，而且触发极其灵敏。
2.  **拿得住单**：低位震荡时，宽阔的卖出阈值避免了频繁被洗出。
3.  **逃顶坚决**：高位时，任何风吹草动（稍微偏离）都会触发减仓。
4.  **自动降频**：在非极端区域（中位），买卖阈值适中，避免了无意义的磨损。
