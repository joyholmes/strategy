# 行业板块估值策略配置指南 (全品类版)

本文档由 AI 策略团队整理，提供了针对中国股市**主流板块的定制化参数配置**。
这些参数经过回测验证，根据各行业的**周期性强弱**、**估值指标适用性**及**历史波动特征**进行了深度优化。

## 一、 策略原理概览

本策略是基于**“均值回归”**的逆向投资策略。

- **适用性**：最适合**周期性行业**（涨跌有规律）和**核心资产**（长牛但有大回撤）。
- **局限性**：不适合**题材妖股**（无估值逻辑）、**夕阳产业**（只有估值杀没有回归）、**长牛不回头**的股票（容易卖飞）。

## 二、 板块配置速查表

| 板块类型       | 推荐标的    | 核心指标   | 特征关键词     | 适用策略                 |
| :------------- | :---------- | :--------- | :------------- | :----------------------- |
| **证券**       | 中信证券    | **PB**     | 强周期、脉冲式 | 左侧深埋，高位快跑       |
| **消费**       | 伊利/海天   | PE         | 稳健、长牛     | 高阈值建仓，宽阈值持有   |
| **白酒**       | 茅台/五粮液 | PE         | 高估值中枢     | 30%分位即是黄金坑，惜售  |
| **医疗**       | 迈瑞/恒瑞   | PE         | 政策敏感、成长 | 关注集采后的估值重塑     |
| **保险**       | 中国平安    | **PB/PEV** | 利率敏感、高波 | 利率低点重仓，反弹分批跑 |
| **猪肉**       | 牧原股份    | **PB**     | 产能周期、困境 | 越亏越买，困境反转暴利   |
| **银行(成长)** | 招商银行    | **PB**     | 优质、成长     | 避免过早止盈，拉高卖出线 |
| **银行(红利)** | 工商银行    | **PB**     | 低波、织布     | 地板价捡漏，吃股息为主   |

## 三、 详细参数代码块

您只需将对应板块的代码块复制替换到 `strategies/valuation_pyramid/config.py` 文件中相应的位置即可。

### 1. 证券板块 (强周期/牛市旗手)

_建议标的：中信证券 (600030.SH), 东方财富 (300059.SZ)_

```python
STOCK_CODE = '600030.SH'

class ValuationParams:
    total_initial_cash = 100000.0
    metric = 'pb' # 必须用PB
    lookback_years = 10

    # 底部漫长，从40%就开始定投关注，但保留重仓在极低位
    buy_tiers = [
        (0.40, 0.2), (0.30, 0.4), (0.20, 0.7), (0.10, 1.0)
    ]
    # 顶部尖锐，一旦高估要果断清仓
    sell_tiers = [
        (0.70, 0.6), (0.80, 0.3), (0.90, 0.1), (0.95, 0.0)
    ]
    use_fixed_reference = False
```

### 7. 银行板块 (成长 vs 红利)

#### 方案 A: 高成长/优质银行 (如招商银行)

_防止卖飞，拉高止盈线_

```python
STOCK_CODE = '600036.SH' # 招商银行

class ValuationParams:
    total_initial_cash = 100000.0
    metric = 'pb'
    lookback_years = 10

    # 优质银行也是银行，低位才买
    buy_tiers = [
        (0.20, 0.3), (0.10, 0.6), (0.05, 0.9), (0.01, 1.0)
    ]
    # 重点优化：拉高卖出线，防止错过主升浪
    sell_tiers = [
        (0.70, 0.5), (0.85, 0.2), (0.95, 0.0)
    ]
    use_fixed_reference = False
```
