# 金字塔双线估值策略 (Valuation Pyramid)

## 1. 核心理念

本策略结合了**“极限时机策略”的高盈亏比**与**“分档定投策略”的容错性**，引入了**滞后区间 (Hysteresis)** 概念。

**逻辑核心：**

1.  **“买入线” (Floor)**：设定在低估区域（如 <30%），确保在该区域内仓位**至少**达到一定水平（越跌越补）。
2.  **“卖出线” (Ceiling)**：设定在高估区域（如 >70%），强制仓位**至多**保留一定水平（越涨越卖）。
3.  **“中间态” (Hold)**：在买入线和卖出线之间的宽阔区域（如 30%~70%），**不做任何操作，维持现有仓位**。

**优势：**
相比于死板的“分档对应”（如 40%分位强制对应 50%仓位），本策略允许：“虽然现在回到了 50%的正常分位，但因为我是从 10%抄底上来的，所以我依然满仓持有，享受主升浪，直到泡沫出现（>70%）才开始减仓”。

## 2. 参数配置

### 买入阶梯 (Buy Tiers)

| 分位点 (Upper Limit) | 最低仓位 (Min Target) | 含义       |
| :------------------- | :-------------------- | :--------- |
| **< 30%**            | **30%**               | 防踏空底仓 |
| **< 20%**            | **70%**               | 主力建仓区 |
| **< 10%**            | **100%**              | 黄金坑满仓 |

### 卖出阶梯 (Sell Tiers)

| 分位点 (Lower Limit) | 最高仓位 (Max Limit) | 含义               |
| :------------------- | :------------------- | :----------------- |
| **> 70%**            | **50%**              | 警戒减半，锁定利润 |
| **> 85%**            | **0%**               | 泡沫清仓，落袋为安 |

（该参数可在 `config.py` 中灵活调整）
